# Zcord

Zcord is a cross-platform communication application inspired by Discord, developed using Flutter. It aims to provide seamless real-time voice and text communication for users across various platforms.

## Features

- **Real-Time Communication**: Engage in instant messaging and voice chats with low latency.
- **Cross-Platform Support**: Available on Android, iOS, web, and desktop platforms.
- **User-Friendly Interface**: Intuitive design ensuring a smooth user experience.
- **Secure Messaging**: End-to-end encryption for all communications.
- **Customizable Channels**: Create and manage text and voice channels as per your community's needs.

## Installation

To get started with Zcord, follow these steps:

### Clone the Repository:

```bash
git clone https://github.com/salergame/Zcord.git
```

### Navigate to the Project Directory:

```bash
cd Zcord
```

### Install Dependencies:

```bash
flutter pub get
```

### Run the Application:

#### For Android:
```bash
flutter run
```

#### For iOS:
```bash
flutter run
```

#### For Web:
```bash
flutter run -d chrome
```

#### For Desktop:
```bash
flutter run -d windows
```
